# Localization and language QA

The frontend loads one JSON resource per language from
`narcotrace-frontend/src/locales/`. English is the fallback and source of truth. User
language is selected on sign-in, persisted locally, and synchronized to `/me` after login.
Urdu sets `dir=rtl`; the bundled Noto fonts are hosted locally for offline use.

Supported locales: `en`, `hi`, `kn`, `ta`, `te`, `ml`, `mr`, `bn`, `gu`, `pa`, `or`, `as`,
and `ur`. `en-XA` is a pseudo-locale for layout testing, not a supported production
language.

Run `npm run check:locales` from the frontend to compare key sets and ICU parameters,
report empty strings and `_todo` drafts, and flag unusually long values. Run
`npx playwright test e2e/i18n.spec.ts` with the compose backend seeded to smoke-test all
production locales, local fonts, RTL, no raw keys, overflow, and login accessibility.

Translation completeness does not mean translation quality. Legal, forensic, verdict, and
Form 6 text must be reviewed by a native speaker and legal authority before production.
See `translations/REVIEW.md` for current draft/review tracking.
